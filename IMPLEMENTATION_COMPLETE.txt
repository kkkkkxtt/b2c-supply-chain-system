  6. Wallet address displayed immediately

PROFILE VIEWING FLOW:
  1. User clicks "Profile" in navigation
  2. Page loads with UserProfile component
  3. All user attributes displayed
  4. Each attribute color-coded:
     - Blue: Name
     - Amber: Email
     - Purple: Role (immutable)
     - Green: Wallet (immutable, with copy)
     - Yellow: Balance
     - Cyan: Contact
     - Rose: Address
     - Indigo/Teal: Timestamps
  5. User can click "Edit Profile"

PROFILE EDITING FLOW:
  1. User clicks "Edit Profile"
  2. Component switches to edit mode
  3. Editable fields become input fields
  4. User makes changes (name, email, contact, address)
  5. Immutable fields remain disabled
  6. User clicks "Save Changes"
  7. API updates database
  8. UI refreshes with new values
  9. LocalStorage updated
  10. Success confirmed

TRANSACTION FLOW WITH WALLET:
  1. User (with wallet: 0x742d35Cc...) creates order
  2. Order includes buyer_wallet_address
  3. Hash generated with wallet context
  4. Recorded on blockchain (ORDER_CREATED event)
  5. Sender: User's wallet_address
  6. On payment: Seller's wallet_address used

Q: Can I change my wallet address?
A: No. Wallet address is immutable - it's your blockchain identity.

Q: What if I forget my wallet address?
A: It's always visible in your profile. You can copy it anytime.

Q: Is my wallet address secure?
A: Yes. It's unique per account and database-protected.

Q: Can someone else use my wallet?
A: No. Wallet addresses are unique with database UNIQUE constraint.

Q: Do I need to enter a wallet during signup?
A: No. The system auto-generates one for you!

Q: Where is my private key stored?
A: Private keys are NOT stored. For production, use external providers.

Q: Can I edit my email after signup?
A: Yes. Email is editable from your profile.

Q: Can I edit my role after signup?
A: No. Role is immutable - like your wallet address.

Q: How is my wallet used in transactions?
A: It's the sender address for all blockchain events you create.

Q: Is the wallet a real Ethereum wallet?
A: Yes, it's a valid Ethereum address format (0x...), but private key not available.
